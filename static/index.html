Zonatic

Indonesia Location Intelligence Platform — mengubah koordinat menjadi konteks wilayah administratif.

API Endpoints

GET /v1/reverse-geocode
Konversi koordinat WGS84 menjadi hierarchy administratif Indonesia.
GET /v1/areas/autocomplete
Pencarian wilayah administratif dengan breadcrumb hierarchy.
GET /v1/areas/{code}
Detail wilayah administratif berdasarkan kode baku.
GET /v1/postal-codes/{code}
Lookup kode pos dan wilayah administratif terkait.
GET /v1/postal-codes/search
Pencarian kode pos berdasarkan kode atau nama wilayah.
GET /v1/areas/{code}/postal-codes
Daftar kode pos yang terhubung dengan wilayah administratif.
